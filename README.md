🧥 AI Wardrobe Recommendation
An intelligent fashion outfit recommender built with React. It helps users discover and save outfit suggestions curated by an AI engine based on personal style preferences and trends.

✨ Features

🎯 Personalized Outfit Recommendations

💖 Add or remove outfits from your wishlist

🎠 Smooth carousel view for browsing looks

🌐 Fully responsive & optimized for all screen sizes

🎨 Clean and modern UI using Tailwind CSS


🧑‍💻 Getting Started
1. Clone the repository
git clone https://github.com/rohitRaut007/Ai-wardrobe-Recommendation.git
cd Ai-wardrobe-Recommendation

3. Install dependencies
npm install
# or
yarn install

3. Start the development server
npm run dev
# or
yarn dev
